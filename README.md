# React Login/Signup System 🔐

A complete authentication system built with React.js featuring secure login, signup with validation, and user dashboard.

## ✨ Features
- **Login/Logout Functionality**
- **Signup with Form Validation**
- **Password Strength Checker**
- **User Dashboard**
- **Responsive Design**
- **Modern UI/UX**
